# Cockroach Racing App (Тараканьи бега)

Простая десктопная игра-симулятор, моделирующая заезд двух участников. Пользователи могут задавать имена бегунам, запускать случайный процесс движения участников до финишной черты и сбрасывать результаты для повторного раунда.

## Особенности игры

* **Кастомизация участников:** текстовые поля позволяют ввести уникальные имена для обоих бегунов перед началом заезда (например, *саймон* и *элвин*).
* **Счетчик дистанции:** под именем каждого участника расположен числовой индикатор, показывающий текущее пройденное расстояние в пикселях.
* **Случайное ускорение:** движение участников происходит случайными рывками, что обеспечивает непредсказуемый финал в каждом заезде.
* **Фиксация победителя:** программа автоматически определяет, кто первым пересёк финишную черту на отметке `680`, и выводит текстовое сообщение сверху (например, *"игрок саймон победил!"*).
* **Управление раундами:** кнопка **"СТАРТ"** запускает заезд, а кнопка **"Сброс"** возвращает участников на исходные позиции и обнуляет дистанцию.

## Как играть

1. Запустите приложение.
2. Введите имена участников в верхние текстовые поля (по умолчанию там стоят значения `0`).
3. Нажмите большую кнопку **"СТАРТ"** внизу экрана, чтобы запустить заезд.
4. Дождитесь, пока один из тараканов доберется до правого края экрана. Сверху появится надпись с именем победителя.
5. Для начала нового заезда нажмите кнопку **"Сброс"** в правом нижнем углу.
